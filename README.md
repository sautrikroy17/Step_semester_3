# Session 8: Object Class Methods, Inner Classes & UML Diagrams

## 📂 Structure
- `classwork/`: In-class practice problems (5 programs)
- `homework/`: Take-home assignment problems (5 programs)

2. **EmployeeLeaveRequestWorkflow.java** - Employee leave request lifecycle with state guards
3. **OnlineExaminationSystem.java** - Online exam evaluation with immutable attempt submissions
4. **HotelBookingSystem.java** - Room availability checking, booking calculation, and cancellations
5. **PaymentProcessingSystem.java** - E-commerce payment processing with polymorphic payment gateways

1. **TheHostelLaundryQueue.java** - Hostel laundry machine booking and wash cycle management
2. **TheAssignmentSubmissionPortal.java** - College assignment submission portal with late penalty policies
3. **TheCampusPremiereTicketCounter.java** - Movie premiere seat reservation with category pricing and release workflows
4. **TheFitZoneMembershipDesk.java** - Campus gym membership lifecycle, check-in validation, and freeze states
5. **TheCampusNoticeBroadcaster.java** - Multi-channel campus notice broadcast system based on target departments
