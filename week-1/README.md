# Week 1: Strings & Fundamental Algorithms

This branch contains solutions for Week 1 practice and homework assignments.

## 📂 Structure
- `classwork/`: In-class practice problems (5 programs)
- `homework/`: Take-home assignment problems (5 programs)

### Classwork (Practice)
1. **RockPaperScissors.java**: Deterministic round evaluator.
2. **PalindromeChecker.java**: Case-insensitive alphanumeric palindrome checker.
3. **BMICalculator.java**: Strict WHO BMI category classifier.
4. **FirstNonRepeatingChar.java**: First unique character locator.
5. **ReverseCustomerName.java**: Two-pointer in-place character reverser.

### Homework (Assignment)
1. **DuplicateSeatChecker.java**: Seat duplicate checker.
2. **TypingAccuracyChecker.java**: Character-by-character difference counter.
3. **TrafficSignalStreak.java**: Longest contiguous green signal streak calculator.
4. **WarehouseInventory.java**: Low stock and out-of-stock monitor.
5. **MovieReviewProfiler.java**: Word frequency counter for sentiment analysis.
