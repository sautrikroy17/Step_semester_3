# STEP Semester 3 - Week 1: Programming with Strings

Solutions for Week 1 practice and homework problems on String manipulation and core Java programming constructs.

### Practice Problems
- `RockPaperScissors.java`: Simulation of Rock-Paper-Scissors arcade rounds with win percentage calculation.
- `PalindromeChecker.java`: Palindrome verification using iterative, recursive, and array-reversal approaches.
- `BMICalculator.java`: Body Mass Index computation and classification for a team wellness report.
- `FirstNonRepeatingChar.java`: Character frequency detection to identify the first unique character.
- `ReverseCustomerName.java`: String traversal and reversal maintaining immutability of the original input.

### Assignment Problems (HW)
- `DuplicateSeatChecker.java`: Exam hall seat number duplicate detection using basic array comparisons.
- `TypingAccuracyChecker.java`: Character-by-character typing test accuracy calculation and first mismatch locator.
- `TrafficSignalStreak.java`: Sequential log scanning to find the longest streak of identical traffic signals.
- `WarehouseInventory.java`: Multi-section inventory comparison and maximum quantity identification.
- `MovieReviewProfiler.java`: Categorization and profiling of review word lengths (short, medium, long).
