# STEP Semester 3 - Week 2: String Operations & Performance

Java solutions for Week 2 practice and homework assignments focusing on String methods, StringBuilder, validation, and performance optimization.

### Practice Problems
- `VowelConsonantCounter.java`: Case-insensitive vowel and consonant counter ignoring whitespaces.
- `CSVStudentRecordParser.java`: CSV line validation and student record formatter.
- `FileExtensionValidator.java`: File extension extractor and validator for accepted formats.
- `MaskedPhoneNumberFormatter.java`: Phone number length/digit validator and masked representation using StringBuilder.
- `BankTransactionRefValidator.java`: Multi-stage normalization and structural validator for transaction reference codes.

### Assignment Problems (HW)
- `AtmPinValidator.java`: Basic length validator for 4-digit ATM PIN entries.
- `WordReversalEncoder.java`: Sentence parser reversing individual words while preserving word order.
- `ProductInventoryParser.java`: Warehouse CSV inventory record parser and field count validator.
- `LibraryIsbnValidator.java`: ISBN-style publisher code and catalog number normalizer and validator.
- `StopWordFrequencyReport.java`: Text punctuation cleaner, stop-word filter, and word frequency ranker.
