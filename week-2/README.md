# Week 2: String Manipulation, ASCII & Performance

This branch contains solutions for Week 2 practice and homework assignments.

## 📂 Structure
- `classwork/`: In-class practice problems (5 programs)
- `homework/`: Take-home assignment problems (5 programs)

### Classwork (Practice)
1. **VowelConsonantCounter.java**: Case-insensitive character classification.
2. **CSVStudentRecordParser.java**: Comma-separated token parser.
3. **FileExtensionValidator.java**: File extension extraction and validation.
4. **MaskedPhoneNumberFormatter.java**: Phone number masking utility.
5. **BankTransactionRefValidator.java**: Banking reference format validator.

### Homework (Assignment)
1. **AtmPinValidator.java**: Numeric ATM PIN format verification.
2. **WordReversalEncoder.java**: Sentence word-order inverter.
3. **ProductInventoryParser.java**: Inventory record field extractor.
4. **LibraryIsbnValidator.java**: ISBN-10 checksum validation.
5. **StopWordFrequencyReport.java**: Text tokenizer and stop-word filter.
