# Week 3: OOP Fundamentals

This branch contains solutions for Week 3 practice and homework assignments.

## 📂 Structure
- `classwork/`: In-class practice problems (5 programs)
- `homework/`: Take-home assignment problems (5 programs)

### Classwork (Practice)
1. **PlacementRecord.java**: Parallel arrays transition to encapsulated class.
2. **MessWallet.java**: Wallet encapsulation with strict balance validation.
3. **Course.java**: Constructor overloading and `this(...)` chaining.
4. **IdCard.java**: Reference assignment and identity testing.
5. **StudentCollegeTracker.java**: Static vs. instance state separation.

### Homework (Assignment)
1. **BookInventory.java**: OOP model tracking book inventory.
2. **PayrollAccount.java**: Salary and bonus encapsulation with tax calculation.
3. **EmployeeProfile.java**: Constructor chaining for staff and intern profiles.
4. **HallTicket.java**: Reference sharing and equality comparisons.
5. **CompanyEmployeeTracker.java**: Shared static tracking with individual employee records.
