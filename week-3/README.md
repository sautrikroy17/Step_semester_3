# Week 3: Object-Oriented Programming Fundamentals

This branch contains solutions for Week 3 practice and homework assignments covering core Object-Oriented Programming concepts in Java: Classes, Objects, Constructors, Encapsulation, Reference Copying, and Static vs Instance Members.

## Practice Problems (Category B)
1. **PlacementRecord.java**: Transitions parallel arrays to an encapsulated `PlacementRecord` class with custom formatted display.
2. **MessWallet.java**: Implements wallet balance encapsulation with strict bounds checking and validation rules.
3. **Course.java**: Demonstrates constructor overloading and chaining using `this(...)` for theory and lab courses.
4. **IdCard.java**: Explores reference assignment, in-place field mutations, and object identity comparison (`==`).
5. **StudentCollegeTracker.java**: Separates instance state from shared static class state (`collegeName`, `studentCount`).

## Homework Problems (Category B)
6. **BookInventory.java**: Replaces parallel arrays with an OOP model tracking book titles, authors, and available copies.
7. **PayrollAccount.java**: Enforces data integrity on basic salary, bonus crediting, and tax deduction logic.
8. **EmployeeProfile.java**: Uses overloaded constructors and constructor chaining to model permanent vs intern employee profiles.
9. **HallTicket.java**: Demonstrates reference sharing, object equality, and identity behavior.
10. **CompanyEmployeeTracker.java**: Models company-wide static tracking alongside individual employee records.
